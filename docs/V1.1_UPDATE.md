# v1.1 update

What changed
- Hook rules rewritten: max 9 words, must create curiosity/stakes/a question in 2 seconds.
- Reels are shorter (target ~24 s, max 30 s) with 2-3 main beats; on-screen text is a short punchy fragment, not a repeat of the voice.
- New visuals: animated glow background, an icon for every beat, original mascot "Byte" (5 expressions). Optional real stock B-roll if PEXELS_API_KEY is set (then the source line adds "Stock visuals: Pexels").
- Sound: original synthesised music pad (or your own tracks in assets/music/), whoosh transitions, music ducks under the voice, loudness normalised to about -15 LUFS.
- Captions: fixed the text running off the screen edges and the overlapping caption lines.
- Mascot is automatically OFF for sensitive or harm-related stories (fire, crash, death, arrest, scam, layoffs, court, health ...) and for anything needing human review. It appears on about 60% of light stories (settings: mascot.probability).
- If the AI provider fails on every story, the run now turns RED and Telegram is notified.
- Workflows pinned to ubuntu-24.04.
- Groq model is auto-discovered (already uploaded earlier).

Optional switches (config/settings.yaml)
  mascot: {enabled: true, probability: 0.6, max_beats: 3}
  media:  {music_mode: auto, music_volume: 0.11, sfx: true, broll: true}
