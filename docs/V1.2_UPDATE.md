# v1.2: the "human" kinetic style is now automatic

Default style is now `kinetic`: text-on-screen Reels with a beat (no AI voice), built from every verified story.

How a Reel is built
1. The AI writes SCENES, not a voice script: a 2-3 line hook, 3-5 detail/alert/relief/twist scenes, and a closing question.
2. The same safety gates run: facts only, every number must be in the sources, no first-person claims, hook score (hookscore.py),
   human-sounding check (detect.py), caption lint (caption.py), then media QA.
3. The renderer assigns colours (never the same colour twice in a row), cuts on the beat, picks graphics the facts support
   (flight route only for a journey, smoke only if the facts mention smoke/fire, check mark only for a good outcome), adds
   punch-in zoom, shake, grain, whoosh/hit sounds and an original beat. No mascot, no voice.
4. About 20 seconds, 1080x1920, H.264/AAC.

Switches (config/settings.yaml)
  video:   {style: kinetic}     # kinetic | classic  (classic = voice-over version from v1.1)
  kinetic: {bpm: 108, max_words: 60, closer_sub: "Tell me below."}
  media:   {music_mode: auto}   # your royalty-free tracks in assets/music/ replace the synthesised beat
